# Report — P05-02

## Summary

Implemented deterministic pool creation and seed-liquidity scripts for the four X Cup pools. `CreatePools.s.sol` reads `tokens.json` and `core.json`, builds address-sorted dynamic-fee `PoolKey` values with the deployed `XCupLiquidityLeagueHook`, initializes all four pools at 1:1, registers them in `XCupLeagueRegistry`, and writes `deployments/<chainId>/pools.json`. `SeedLiquidity.s.sol` reads the generated manifests, mints owner-only demo balances to the deployer, deploys a script helper for v4 unlock settlement, adds full-range liquidity to all four pools, and writes `deployments/<chainId>/seed.json`.

Fresh Anvil validation passed end-to-end for `DeployTokens -> DeployCore -> CreatePools -> SeedLiquidity`. All four pool IDs returned `true` from `registry.isRegisteredPool`. A post-seed BRA pool swap succeeded locally through the helper, proving the seeded pool can execute the hook-backed swap path.
