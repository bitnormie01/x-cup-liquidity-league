Behavior after this change:

- If `POOL_MANAGER_ADDRESS` is set, `DeployCore` uses that external PoolManager and writes `"poolManagerMode": "external"`.
- If `POOL_MANAGER_ADDRESS` is unset and `block.chainid == 31337`, `DeployCore` keeps the local-Anvil project-owned fallback.
- If `POOL_MANAGER_ADDRESS` is unset on a non-local chain, `DeployCore` deploys a project-owned PoolManager only when `DEPLOY_OWN_POOL_MANAGER=true`.
- Otherwise, `DeployCore` reverts with `PoolManagerAddressRequired()`.
