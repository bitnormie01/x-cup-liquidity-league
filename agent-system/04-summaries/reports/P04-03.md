# Report — P04-03

## Summary

Added the swap-only anti-wash state machine to `XCupLiquidityLeagueHook.sol`. The hook now tracks per-user/per-pool swap activity, previews cooldown/reversal/burst status through one shared pure `_computeStatus` helper, applies the +25 bps fee penalty in `beforeSwap`, strips supporter discount when flagged, zeros swap points through the wash multiplier in `afterSwap`, and emits `WashPenaltyApplied` for flagged swaps.

Flagged swaps still complete and update activity state. `_afterAddLiquidity` was not changed.
