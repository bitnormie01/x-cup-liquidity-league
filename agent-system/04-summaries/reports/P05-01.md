## Risks / Caveats

- `DeployCore` auto-deploys `PoolManager` only when `block.chainid == 31337` and `POOL_MANAGER_ADDRESS` is unset. On any other chain, missing `POOL_MANAGER_ADDRESS` reverts.
- The CREATE2 helper is intentionally deployed as part of the script because Foundry script contracts are ephemeral and cannot safely be used as the CREATE2 deployer.
- `DemoQuoteToken` constructor differs from the D12 prose; the script follows the installed contract and deploys `DemoQuoteToken(owner)`, which sets name/symbol internally.
- Local anvil deployment JSON files were generated but not committed.
