## Implementation Notes

### MatchStateSimulator

- Visible in dev mode or with `?admin=1`.
- Reads `registry.controller()` and `registry.owner()`.
- Disables writes unless the connected wallet matches controller or owner.
- Uses existing `TeamSelector`.
- Renders all six match states from `match-states.ts`.
- Calls `registry.setMatchState(teamId, state, reason)`.
- Waits for receipt and shows status.
- Applies a 3-second cooldown after success.

### EventLog

- Captures:
  - `DynamicFeeApplied`
  - `TeamPointsAwarded`
  - `WashPenaltyApplied`
  - `MatchStateUpdated`
- Uses bounded polling via viem `getLogs` every 5 seconds.
- The queried window is 100 blocks because X Layer testnet RPC returned a hard error for ranges over 100 blocks.
- Shows last 20 decoded events with event name, resolved team symbol, user where available, key fields, and explorer transaction link.
- Includes loading, empty, and error states.

### ContractProofPanel

- Shows chain ID and network name.
- Links xUSD, BRA, ARG, FRA, GER on OKX Explorer.
- Links PoolManager, Registry, TeamPassport, Hook, and LiquiditySeeder helper.
- Lists all four pool IDs.
- Clearly discloses the project-owned PoolManager.
