## Implementation Notes

- Extended the hook ABI with `getTeamScore(bytes32)` and `feeForState(uint8)`.
- Added registry ABI support for `matchStateOfTeam(bytes32)`.
- Added match-state metadata for enum values 0 through 5 with labels and color classes.
- Added `useLeagueData`, which batches reads for all four teams and all six fee states.
- Used 5-second polling via wagmi query `refetchInterval: 5000`. This was chosen over block watching to keep the phase small and avoid noisy frontend state wiring.
- Leaderboard sorting is deterministic: `totalPoints` desc, `lpPoints` desc, `fanCount` desc, then symbol asc.
- Pool IDs are displayed directly. Explorer links point to team token addresses on OKX Explorer rather than inventing unsupported pool URLs.
