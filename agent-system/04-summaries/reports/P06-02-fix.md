# P06-02 Fix Report - Hook Contribution Read

## Summary

Fixed the P06-02 frontend contribution read bug. The frontend was calling `getUserContribution(address,bytes32)`, but the deployed hook exposes the public mapping getter `contributions(address,bytes32)`.

## Exact Bug

`XCupLiquidityLeagueHook` has:

```solidity
mapping(address => mapping(bytes32 => UserContribution)) public contributions;
```

The deployed ABI getter is therefore `contributions(address,bytes32)`, not `getUserContribution(address,bytes32)`.
