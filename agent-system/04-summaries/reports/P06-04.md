## Helper / Pool API Notes

- ERC-20 ABI now includes `allowance`, `approve`, `balanceOf`, and `decimals`.
- `V4PoolActionHelper` ABI includes:
  - `swap(address payer, PoolKey key, SwapParams params, bytes hookData)`
  - `modifyLiquidity(address payer, PoolKey key, ModifyLiquidityParams params, bytes hookData)`
- `frontend/lib/pools.ts` builds PoolKey values from the committed deployment data:
  - `fee = 8388608`
  - `tickSpacing = 60`
  - `hooks = deployments.core.hook`
- Swap exact-input uses negative `amountSpecified`.
- Hook data is the connected wallet address hex directly, which is raw 20-byte address data.
- v4 price-limit constants:
  - zero-for-one: `4295128740`
  - one-for-zero: `1461446703485210103287273052203988822378723970341`
- Liquidity support uses full-range ticks `-887220` / `887220`, zero salt, and MVP `liquidityDelta = parsed xUSD amount`.

## SwapPanel

- Team selector for BRA/ARG/FRA/GER.
- Direction toggle for `xUSD -> TEAM` and `TEAM -> xUSD`.
- Amount input.
- Reads input-token balance, allowance, and decimals.
- Approves `deployments.core.liquiditySeeder` when allowance is insufficient.
- Calls helper `swap` once allowance is sufficient.
- Shows active fee preview from registry match state plus hook `feeForState`.
- Shows approve/swap pending, submitted, confirmed, and error states.

## LiquidityPanel

- Team selector for BRA/ARG/FRA/GER.
- xUSD side amount input.
- Computes the matching team-token display amount as the same user input for the 1:1 MVP.
- Reads xUSD and selected team-token balances, allowances, and decimals.
- Approves xUSD and team token independently when needed.
- Calls helper `modifyLiquidity` with full-range ticks once both allowances are sufficient.
