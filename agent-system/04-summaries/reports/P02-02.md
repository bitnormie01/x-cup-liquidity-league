# Report — P02-02

## Summary

Implemented `contracts/src/TeamPassport.sol` as the MVP soulbound ERC-721 passport contract. The contract inherits only OpenZeppelin v5 `ERC721` and `Ownable`, uses the exact `X Cup Team Passport` / `XCUP-PASS` identity, and accepts the owner as a constructor argument. Each wallet can mint one passport for a non-zero `bytes32 teamId`, with `passportOf`, `tokenIdOf`, `teamFanCount`, and `nextTokenId` updated according to directive D4. The read helpers `teamOf`, `hasPassport`, and `isSupporter` expose the data future Hook phases need for loyalty multipliers and supporter discounts. Transfers are blocked through the OZ v5 `_update` hook whenever both `from` and `to` are non-zero, while mints and theoretical burns remain permitted. No tests were added because P02-03 owns token and passport tests.
