## ABI Notes

- ERC-20 faucet ABI covers `balanceOf`, `FAUCET_AMOUNT`, `FAUCET_COOLDOWN`, `lastFaucetAt`, `faucetMint`, `symbol`, and `decimals`.
- TeamPassport ABI covers `mintPassport`, `hasPassport`, `passportOf`, `tokenIdOf`, `teamOf`, and `teamFanCount`.
- Hook ABI uses `getUserContribution(address,bytes32)` returning the `UserContribution` tuple from the installed contract: `swapPoints`, `lpPoints`, `totalPoints`, `lastActionAt`.

## UI Notes

- Faucet panel renders xUSD, BRA, ARG, FRA, and GER rows.
- Each row reads balance, faucet amount, cooldown, and last faucet timestamp.
- Claim buttons call `faucetMint(connectedAddress)` and wait for transaction receipts before refetching reads.
- Claim buttons are disabled when disconnected, wrong network, pending/confirming, or cooldown active.
- Team selector single-selects BRA/ARG/FRA/GER using team IDs from the committed deployment data.
- Passport card handles disconnected, wrong-network, unminted, minting, and minted states.
- Minting calls `mintPassport(teamId)`, waits for receipt, then refetches passport reads.
- Minted state shows team, token ID, `Soulbound`, and hook contribution numbers.
