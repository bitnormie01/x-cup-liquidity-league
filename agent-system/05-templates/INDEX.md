## Best practice

When filling a template:
- Replace ALL `<placeholders>` and bracketed `[example]` text.
- Delete any sections that genuinely don't apply, BUT leave the heading + the literal text `N/A` so reviewers know it was considered.
- Never invent fields. If something needs to be said and there's no slot for it, add a `## Notes` section at the bottom.
