# Directive — D11 for P04-03

## Goal

Add the anti-wash state machine to `XCupLiquidityLeagueHook.sol`: detect cooldown / reversal / burst violations, set `washMult = 0` for flagged swaps, apply the `+25 bps` fee penalty in `beforeSwap`, strip the supporter discount when flagged, and emit `WashPenaltyApplied` from `afterSwap`. Provide a public `previewAntiWash` view for the frontend. Tests cover all three violation reasons + the unflagged path.

This closes Plan 04's product feature set — after this lands, only P04-04 (full hook tests) remains before deployment.

### 4. Pure status computation

Factor the wash detection into a single pure helper so `previewAntiWash` and `_updateAntiWashState` share one code path:

```solidity
function _computeStatus(
    UserPoolActivity memory activity,
    uint64 nowTs,
    IPoolManager.SwapParams calldata params
) internal pure returns (AntiWashStatus memory status) {
    if (activity.lastSwapAt == 0) {
        // first swap from this user in this pool — not flagged
        return AntiWashStatus({
            isFlagged: false,
            reason: WashReason.NONE,
            penaltyBps: 0,
            pointsMultiplierBps: uint16(uint256(DEFAULT_MULTIPLIER_BPS))
        });
    }

    uint64 delta = nowTs - activity.lastSwapAt;

    if (delta < ANTI_WASH_COOLDOWN_SEC) {
        return AntiWashStatus({
            isFlagged: true,
            reason: WashReason.COOLDOWN,
            penaltyBps: WASH_PENALTY_BPS,
            pointsMultiplierBps: 0
        });
    }

    if (delta < ANTI_WASH_REVERSAL_SEC && params.zeroForOne != activity.lastZeroForOne) {
        return AntiWashStatus({
            isFlagged: true,
            reason: WashReason.REVERSAL,
            penaltyBps: WASH_PENALTY_BPS,
            pointsMultiplierBps: 0
        });
    }

    bool windowExpired = nowTs - activity.windowStartAt >= ANTI_WASH_BURST_WINDOW_SEC;
    if (!windowExpired && activity.swapsInWindow + 1 > ANTI_WASH_BURST_MAX_SWAPS) {
        return AntiWashStatus({
            isFlagged: true,
            reason: WashReason.BURST,
            penaltyBps: WASH_PENALTY_BPS,
            pointsMultiplierBps: 0
        });
    }

    return AntiWashStatus({
        isFlagged: false,
        reason: WashReason.NONE,
        penaltyBps: 0,
        pointsMultiplierBps: uint16(uint256(DEFAULT_MULTIPLIER_BPS))
    });
}
```

### 5. Preview (view, no mutation)

### 6. Update (mutating, called from `_afterSwap`)

```solidity
function _updateAntiWashState(
    address user,
    PoolId poolId,
    IPoolManager.SwapParams calldata params
) internal returns (AntiWashStatus memory status) {
    UserPoolActivity storage activity = userPoolActivity[user][poolId];
    status = _computeStatus(activity, uint64(block.timestamp), params);

    // roll the burst window
    uint64 nowTs = uint64(block.timestamp);
    if (activity.windowStartAt == 0 || nowTs - activity.windowStartAt >= ANTI_WASH_BURST_WINDOW_SEC) {
        activity.windowStartAt = nowTs;
        activity.swapsInWindow = 1;
    } else {
        // saturating increment — never overflow the uint32 (in practice irrelevant, defensive)
        if (activity.swapsInWindow < type(uint32).max) {
            activity.swapsInWindow += 1;
        }
    }

    activity.lastSwapAt = nowTs;
    activity.lastZeroForOne = params.zeroForOne;
    activity.lastAmountAbs = _absInt256(params.amountSpecified);
}
```

### 7. Wire into `_beforeSwap`

Replace the existing `penalty = 0` stub and the unconditional `discount` line. The body becomes:

```solidity
function _beforeSwap(
    address sender,
    PoolKey calldata key,
    IPoolManager.SwapParams calldata params,
    bytes calldata hookData
) internal returns (bytes4, BeforeSwapDelta, uint24) {
    PoolId poolId = key.toId();
    if (!registry.isRegisteredPool(poolId)) {
        return (IHooks.beforeSwap.selector, BeforeSwapDeltaLibrary.ZERO_DELTA, 0);
    }

    bytes32 teamId = registry.getTeamByPool(poolId);
    XCupLeagueRegistry.MatchState state = registry.getMatchStateByPool(poolId);
    address user = _resolveUser(sender, hookData);

    AntiWashStatus memory preview = _computeStatus(
        userPoolActivity[user][poolId],
        uint64(block.timestamp),
        params
    );

    uint24 base = feeForState[state];
    uint24 discount = (!preview.isFlagged && passport.isSupporter(user, teamId))
        ? PASSPORT_DISCOUNT_BPS
        : 0;
    uint24 penalty = preview.penaltyBps;
    uint24 finalFee = _computeFee(base, discount, penalty);

    emit DynamicFeeApplied(poolId, teamId, user, state, base, discount, penalty, finalFee);

    return (
        IHooks.beforeSwap.selector,
        BeforeSwapDeltaLibrary.ZERO_DELTA,
        finalFee | LPFeeLibrary.OVERRIDE_FEE_FLAG
    );
}
```

### 8. Wire into `_afterSwap`

Replace the `washMult = DEFAULT_MULTIPLIER_BPS;` line with the real call, and emit `WashPenaltyApplied` when flagged. The body becomes:

```solidity
function _afterSwap(
    address sender,
    PoolKey calldata key,
    IPoolManager.SwapParams calldata params,
    BalanceDelta,
    bytes calldata hookData
) internal returns (bytes4, int128) {
    PoolId poolId = key.toId();
    if (!registry.isRegisteredPool(poolId)) {
        return (IHooks.afterSwap.selector, int128(0));
    }

    address user = _resolveUser(sender, hookData);
    bytes32 teamId = registry.getTeamByPool(poolId);

    AntiWashStatus memory status = _updateAntiWashState(user, poolId, params);

    uint256 normalizedVolume = _absInt256(params.amountSpecified);
    uint256 loyaltyMult = passport.isSupporter(user, teamId)
        ? LOYALTY_MULTIPLIER_BPS
        : DEFAULT_MULTIPLIER_BPS;
    uint256 washMult = uint256(status.pointsMultiplierBps);
    // forge-lint: disable-next-line(divide-before-multiply)
    uint256 points = (normalizedVolume * loyaltyMult / 10_000) * washMult / 10_000 / POINT_UNIT;

    TeamScore storage ts = scores[teamId];
    ts.swapPoints += points;
    ts.totalPoints += points;
    ts.lastUpdatedAt = uint64(block.timestamp);

    UserContribution storage uc = contributions[user][teamId];
    uc.swapPoints += points;
    uc.totalPoints += points;
    uc.lastActionAt = uint64(block.timestamp);

    emit TeamPointsAwarded(poolId, teamId, user, PointSource.SWAP, normalizedVolume, loyaltyMult, points);

    if (status.isFlagged) {
        emit WashPenaltyApplied(poolId, teamId, user, status.reason, status.penaltyBps, block.timestamp);
    }

    return (IHooks.afterSwap.selector, int128(0));
}
```

Note: the swap still executes, only points + fees are adjusted. **Do not revert** on flagged swaps.

### 9. Test file: `contracts/test/HookAntiWash.t.sol`

New test file. Each test deploys hook + registry + passport, registers a team + pool, and calls the hook from `vm.prank(address(poolManagerMock))`. Use `vm.warp` for time control.

Required tests:
- `test_FirstSwapIsNotFlagged` — single afterSwap call → status not flagged in subsequent `previewAntiWash`, no `WashPenaltyApplied` event.
- `test_CooldownViolationFlagsSecondSwap` — two `afterSwap` calls within 60 s → second emits `WashPenaltyApplied` with `WashReason.COOLDOWN`; awarded points = 0 (team & user `swapPoints` increase only by first call's amount).
- `test_ReversalViolationFlags` — first swap `zeroForOne=true`, warp to 100 s later, second swap `zeroForOne=false` (within 180 s) → `WashReason.REVERSAL`, points = 0.
- `test_BurstViolationFlagsSixthSwap` — 6 swaps in same pool spaced 70 s apart (each above cooldown, same direction). Sixth flagged with `WashReason.BURST`. Use `vm.warp(block.timestamp + 70)` between calls.
- `test_BeforeSwapAppliesPenaltyAndStripsDiscountForFlaggedUser` — passport-holder, do one swap to record activity, then `previewFee`-style check that next `beforeSwap` returns final fee = baseFee + penalty (no discount since flagged); event shows `discountBps = 0, penaltyBps = WASH_PENALTY_BPS`.
- `test_PreviewAntiWashIsViewOnly` — call `previewAntiWash`, then verify `userPoolActivity` storage unchanged.
- `test_BurstWindowRollsAfter10Minutes` — 5 swaps within window, then warp 600 s, 6th swap NOT flagged (window reset).
- `test_FlaggedSwapStillUpdatesActivityTimestamps` — even on a flagged second swap, `lastSwapAt` advances.

Run `forge test --match-contract HookAntiWashTest -vvv` and the full suite.

## Constraints

- **Solidity 0.8.26 only.**
- **Pure shared computation:** `_computeStatus` MUST be pure and shared between `previewAntiWash` and `_updateAntiWashState`. Do not duplicate the logic into two implementations.
- **`_previewAntiWash` (or its inline equivalent in `_beforeSwap`) MUST NOT mutate storage.** The whole point is gas-cheap reads.
- **Do not change the points formula** in `_afterSwap` — only swap the `washMult` source. The order of operations and lint disable stay identical to P04-02.
- **Window-rolling:** reset `windowStartAt` on entry when expired; increment `swapsInWindow` only after the reset check. Off-by-one bugs here will fail the burst test. Trace the 6-swap test by hand before submitting.
- **Time math:** always cast `block.timestamp` to `uint64` for storage reads; the subtraction `nowTs - lastSwapAt` is safe because we already early-return when `lastSwapAt == 0`.
- **Tests must use `vm.warp` explicitly.** Never rely on default block time progression.
- **Do not** add `_previewAntiWash` as an internal helper that gets called from `_updateAntiWashState` — share the pure `_computeStatus` helper directly to avoid double-reads.
- No `console.log`. No commented-out blocks. Every TODO references the phase that closes it (no new TODOs expected — anti-wash is the closing piece).
