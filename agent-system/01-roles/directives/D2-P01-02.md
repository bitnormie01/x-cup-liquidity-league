# Directive — D2 for P01-02

## Goal

Wire X Layer testnet + mainnet RPC and explorer config into `contracts/foundry.toml`, ship a `.env.example`, document the network section in the root README, and verify testnet RPC connectivity with `cast`. No code or deployments — config only.

## Scope (In)

- Append to `contracts/foundry.toml`:
  ```toml
  [rpc_endpoints]
  xlayer_testnet = "${XLAYER_TESTNET_RPC}"
  xlayer_mainnet = "${XLAYER_MAINNET_RPC}"

  [etherscan]
  xlayer_testnet = { key = "${OKX_EXPLORER_API_KEY}", url = "https://www.okx.com/web3/explorer/xlayer-test/api", chain = 1952 }
  xlayer_mainnet = { key = "${OKX_EXPLORER_API_KEY}", url = "https://www.okx.com/web3/explorer/xlayer/api",      chain = 196  }
  ```
  If OKX does not expose an Etherscan-compatible verifier, leave a `# TODO(P05)` comment next to the `[etherscan]` block and continue — do not block on verification config.
- Create `contracts/.env.example` (committed) with exactly these keys:
  ```
  XLAYER_TESTNET_RPC=https://testrpc.xlayer.tech/terigon
  XLAYER_MAINNET_RPC=https://rpc.xlayer.tech
  DEPLOYER_PRIVATE_KEY=
  OKX_EXPLORER_API_KEY=
  ```
  Do NOT create a real `.env` and do NOT generate or paste any deployer key — the user manages that.
- Update the root `README.md`. Add a `## Networks` section (under the existing stub paragraph) listing:
  - X Layer testnet: Chain ID `1952`, primary RPC `https://testrpc.xlayer.tech/terigon`, fallback RPC `https://xlayertestrpc.okx.com/terigon`, explorer `https://www.okx.com/web3/explorer/xlayer-test`.
  - X Layer mainnet: Chain ID `196`, primary RPC `https://rpc.xlayer.tech`, fallback RPC `https://xlayerrpc.okx.com`, explorer `https://www.okx.com/web3/explorer/xlayer`.
  - Setup instruction: `cd contracts && cp .env.example .env` then fill the required keys (deployer key managed by the user).
- Verify RPC connectivity from the Executor shell:
  ```bash
  cd contracts
  export $(grep -v '^#' .env.example | xargs)   # use example URLs for the read-only check
  cast chain-id --rpc-url "$XLAYER_TESTNET_RPC"
  ```
  Expected output: `1952`. Paste the verbatim output into the report's Tests table. If the primary RPC returns a 502 or fails, retry once with the fallback `https://xlayertestrpc.okx.com/terigon`, record which one worked, and note the swap.
- Confirm `.env` is correctly gitignored: `touch contracts/.env && git status --porcelain contracts/.env` must show no entry. Delete the temporary `.env` after the check.
