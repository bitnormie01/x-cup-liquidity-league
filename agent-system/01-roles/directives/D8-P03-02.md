# Directive — D8 for P03-02

## Goal

Add focused Foundry tests for `XCupLeagueRegistry.sol` so the registry lifecycle, controller permissions, pool mapping reads, and custom revert paths are covered before Hook work begins.

## Scope (In)

- Add `contracts/test/XCupLeagueRegistry.t.sol`.
- Cover team registration:
  - successful `registerTeam` emits `TeamRegistered`.
  - duplicate team registration reverts with `TeamAlreadyRegistered`.
  - `bytes32(0)` team id reverts with `InvalidTeamId`.
  - zero token address reverts with `InvalidToken`.
- Cover pool registration:
  - registering a pool before its team exists reverts with `TeamNotRegistered`.
  - duplicate pool registration reverts with `PoolAlreadyRegistered`.
  - zero `fanToken` or zero `quoteToken` reverts with `InvalidToken`.
  - `getTeamByPool`, `getMatchStateByPool`, and `isRegisteredPool` return expected values after registration.
  - unregistered pool reads revert with `PoolNotRegistered`.
- Cover team list ordering:
  - `getTeamIds()` returns insertion order across at least 3 sequential registrations.
- Cover match-state/controller behavior:
  - default owner can call `setMatchState`.
  - current controller can call `setMatchState` and emits `MatchStateUpdated`.
  - non-controller/non-owner call reverts with `NotController`.
  - unknown or zero team ids revert with the matching custom errors.
  - `setController` by owner emits `ControllerUpdated`, updates effective controller permissions, and rejects `address(0)` with `InvalidController`.
  - `setController` by non-owner reverts with the OpenZeppelin Ownable custom error.
- Run and report:
  - `forge test --match-contract XCupLeagueRegistryTest -vvv`
  - `forge coverage --report summary`
  - `forge fmt --check`
  - `git diff -- contracts/test/XCupLeagueRegistry.t.sol`
- Write report `agent-system/04-summaries/reports/P03-02.md`.
- Update `agent-system/03-state/state-counter.md`, `agent-system/03-state/phase-status.md`, and `agent-system/04-summaries/execution-log.md`.

## Scope (Out)

- Do NOT modify `contracts/src/XCupLeagueRegistry.sol` unless a test exposes a genuine bug that blocks the P03-02 acceptance criteria; if that happens, keep the fix minimal and document it in the report.
- Do NOT touch Hook contracts, deployment scripts, frontend, remappings, dependencies, cache, out, or broadcast.
- Do NOT add Hook integration tests, fuzz tests, pool-manager setup, or frontend reads.
- Do NOT change public registry function signatures or event/error names without raising `BLOCKED`.
