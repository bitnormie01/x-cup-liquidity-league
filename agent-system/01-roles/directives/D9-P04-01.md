# Directive — D9 for P04-01

## Goal

Stand up `XCupLiquidityLeagueHook.sol` inheriting v4-periphery `BaseHook`. Wire the constructor (PoolManager + Registry + Passport + owner), declare hook permissions for `beforeSwap` / `afterSwap` / `afterAddLiquidity`, populate the match-state fee table, and implement the `beforeSwap` callback so it computes the dynamic LP fee, emits `DynamicFeeApplied`, and returns the override-flagged fee. `_afterSwap` and `_afterAddLiquidity` exist as no-op stubs only — real logic lands in P04-02/P04-03.

This is the core product. Get it compiling and emitting the event correctly. Anti-wash and scoring are intentionally deferred.

## Scope (In)

- New file: `contracts/src/XCupLiquidityLeagueHook.sol`.
- Inherit `BaseHook` (from v4-periphery) and OpenZeppelin `Ownable`.
- Immutable state:
  - `XCupLeagueRegistry public immutable registry;`
  - `TeamPassport public immutable passport;`
- Constructor signature exactly as in the phase file (`_pm`, `_registry`, `_passport`, `_owner`).
- `getHookPermissions()`:
  - `beforeSwap: true, afterSwap: true, afterAddLiquidity: true`.
  - **Every other flag false.** All return-delta flags false.
- Constants:
  - `uint24 public constant MIN_FEE_BPS = 25;`
  - `uint24 public constant MAX_FEE_BPS = 200;`
  - `uint24 public constant PASSPORT_DISCOUNT_BPS = 5;`
  - `uint24 public constant WASH_PENALTY_BPS = 25;`
- Storage:
  - `mapping(XCupLeagueRegistry.MatchState => uint24) public feeForState;` populated in constructor:
    - `PRE_MATCH = 30, LIVE_NORMAL = 50, GOAL_SHOCK = 150, RED_CARD = 100, PENALTY = 125, FINAL_WHISTLE = 75`.
- Struct: `FeeBreakdown { uint24 baseFeeBps; uint24 discountBps; uint24 penaltyBps; uint24 finalFeeBps; }`.
- Helper: `_resolveUser(address sender, bytes calldata hookData) internal pure returns (address)`:
  - If `hookData.length >= 20` → decode first 20 bytes as address.
  - Else → return `sender`.
- Helper: `_computeFee(uint24 base, uint24 discount, uint24 penalty) internal pure returns (uint24)`:
  - Saturating subtraction (no underflow): `int256 raw = int256(uint256(base)) - int256(uint256(discount)) + int256(uint256(penalty));`
  - Clamp to `[MIN_FEE_BPS, MAX_FEE_BPS]`.
  - Return as `uint24`.
- `_beforeSwap(address sender, PoolKey calldata key, IPoolManager.SwapParams calldata params, bytes calldata hookData) internal override returns (bytes4, BeforeSwapDelta, uint24)`:
  - `PoolId poolId = key.toId();`
  - If `!registry.isRegisteredPool(poolId)` → return `(BaseHook.beforeSwap.selector, BeforeSwapDeltaLibrary.ZERO_DELTA, 0)` (no override, no event).
  - Resolve `teamId = registry.getTeamByPool(poolId)`.
  - Resolve `state = registry.getMatchStateByPool(poolId)`.
  - Resolve `user = _resolveUser(sender, hookData)`.
  - `base = feeForState[state];`
  - `discount = passport.isSupporter(user, teamId) ? PASSPORT_DISCOUNT_BPS : 0;`
  - `penalty = 0;` (stub — anti-wash lands in P04-03; add a `// TODO(P04-03)` comment).
  - `finalFee = _computeFee(base, discount, penalty);`
  - Emit `DynamicFeeApplied(poolId, teamId, user, state, base, discount, penalty, finalFee)`.
  - Return `(BaseHook.beforeSwap.selector, BeforeSwapDeltaLibrary.ZERO_DELTA, uint24(finalFee) | LPFeeLibrary.OVERRIDE_FEE_FLAG)`. If `LPFeeLibrary.OVERRIDE_FEE_FLAG` isn't exported by the installed v4 version, use the literal `0x400000` and add a code comment `// override flag — LPFeeLibrary symbol missing in installed v4`.
- `_afterSwap(...)` stub: return `(BaseHook.afterSwap.selector, int128(0));`. Add `// TODO(P04-02)`.
- `_afterAddLiquidity(...)` stub: return `(BaseHook.afterAddLiquidity.selector, BalanceDeltaLibrary.ZERO_DELTA);`. Add `// TODO(P04-02)`.
- Event:
  ```solidity
  event DynamicFeeApplied(
      PoolId indexed poolId,
      bytes32 indexed teamId,
      address indexed user,
      XCupLeagueRegistry.MatchState state,
      uint24 baseFeeBps,
      uint24 discountBps,
      uint24 penaltyBps,
      uint24 finalFeeBps
  );
  ```
- Owner-only setters:
  - `setFeeForState(XCupLeagueRegistry.MatchState s, uint24 feeBps) external onlyOwner` — clamp to `[MIN_FEE_BPS, MAX_FEE_BPS]`, revert with a named error on out-of-range.
  - `setFeeBounds(uint24 newMin, uint24 newMax) external onlyOwner` — store as overridable state vars (replace the constants with state vars only if the phase file currently mandates them constant; if both constants and setters conflict, keep constants and OMIT `setFeeBounds` — call this out in the report).
- Compile-only test: `contracts/test/HookCompile.t.sol`:
  - Imports the hook + concrete dependencies (Registry, Passport).
  - Deploys a mock pool manager address (you may use `address(0xBEEF)` cast to `IPoolManager` — the hook is just being instantiated, not run).
  - Calls `new XCupLiquidityLeagueHook(IPoolManager(address(0xBEEF)), registry, passport, owner)` inside a test and asserts `getHookPermissions().beforeSwap == true` and the two siblings.
  - Just one happy-path constructor test — full callback testing is P04-04.
- Update state files + log per protocol.
