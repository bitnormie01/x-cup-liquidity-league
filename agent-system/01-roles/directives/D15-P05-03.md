# Directive — D15 for P05-03

## Goal

Resume P05-03 after local deployment environment setup. Complete X Layer testnet deployment, commit deployment manifests, update README with deployed addresses, run smoke checks, and document best-effort verification results.

## Scope (In)

### 1. Required local environment before any broadcast

Do not commit `.env`. Confirm locally that either `contracts/.env` exists or equivalent shell env vars are exported.

Required values:

```bash
XLAYER_TESTNET_RPC=https://testrpc.xlayer.tech/terigon
DEPLOYER_PRIVATE_KEY=<local-testnet-deployer-private-key>
DEPLOY_OWN_POOL_MANAGER=true
```

Optional:

```bash
OKX_EXPLORER_API_KEY=<key-if-available>
POOL_MANAGER_ADDRESS=<only-if-confirmed-canonical-xlayer-testnet-poolmanager>
```

If `POOL_MANAGER_ADDRESS` is not provided, use `DEPLOY_OWN_POOL_MANAGER=true` and clearly disclose project-owned PoolManager in README/report.

### 2. Pre-flight checks

From `contracts/`, run and record:

```bash
cast chain-id --rpc-url xlayer_testnet
cast wallet address --private-key $DEPLOYER_PRIVATE_KEY
cast balance <derived-deployer-address> --rpc-url xlayer_testnet
```

Acceptance threshold: deployer must have enough X Layer testnet OKB for all four scripts. If balance is zero or clearly insufficient, stop before broadcasts and keep P05-03 blocked with a short updated report.

### 3. Deploy to X Layer testnet

Run in order:

```bash
forge script script/DeployTokens.s.sol --rpc-url xlayer_testnet --private-key $DEPLOYER_PRIVATE_KEY --broadcast
DEPLOY_OWN_POOL_MANAGER=true forge script script/DeployCore.s.sol --rpc-url xlayer_testnet --private-key $DEPLOYER_PRIVATE_KEY --broadcast
forge script script/CreatePools.s.sol --rpc-url xlayer_testnet --private-key $DEPLOYER_PRIVATE_KEY --broadcast
forge script script/SeedLiquidity.s.sol --rpc-url xlayer_testnet --private-key $DEPLOYER_PRIVATE_KEY --broadcast
```

If using a provided external `POOL_MANAGER_ADDRESS`, omit `DEPLOY_OWN_POOL_MANAGER=true` and document `poolManagerMode = external`.

### 4. Commit deployment manifests

Commit testnet artifacts only:

```text
deployments/1952/tokens.json
deployments/1952/core.json
deployments/1952/pools.json
deployments/1952/seed.json

deployments/xlayer-testnet/tokens.json
deployments/xlayer-testnet/core.json
deployments/xlayer-testnet/pools.json
deployments/xlayer-testnet/seed.json
```

Do not commit `deployments/31337/`.

### 5. Smoke checks

Run and record:

- `cast chain-id --rpc-url xlayer_testnet` = `1952`
- `cast code` non-empty for xUSD, one fan token, TeamPassport, Registry, Hook, PoolManager, and seed helper if deployed
- `registry.getTeamIds()` returns four entries
- `registry.isRegisteredPool(poolId)` returns true for all four pools
- `hook.getTeamScore(<BRA_TEAM_ID>)` returns a struct
- One helper swap on testnet if practical; if not practical, document why without blocking if deployment and pool registration succeeded

### 6. Verification and README

Attempt OKX explorer verification if API key/config works. Do not block if verification fails; paste concise failure reason in report.

Update root `README.md` with:

- X Layer testnet deployed address table
- Explorer links
- pool IDs
- reproduction commands
- known limitations, including project-owned PoolManager and helper-owned seeded liquidity if applicable
