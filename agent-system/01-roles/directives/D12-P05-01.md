# Directive — D12 for P05-01

## Context

P04-04 (full hook test battery) has been **skipped** by Mastermind decision under deadline pressure. The 19 existing hook unit tests (compile/scoring/anti-wash) cover individual callback behavior; P05-01's local-anvil pre-flight serves as the integration validation P04-04 would have produced. If a hook-integration bug surfaces during deploy, we'll backfill then.

## Goal

Write Foundry scripts that deploy the full contract stack in a deterministic, replayable order. The hook's deployment uses CREATE2 with a salt mined locally so its address bits encode `{beforeSwap, afterSwap, afterAddLiquidity}` exactly. Scripts must run successfully under a local `anvil` fork before any testnet attempt.

This phase produces scripts only. Testnet deployment is P05-03. Pool creation is P05-02.

## Scope (In)

### 1. `contracts/script/DeployTokens.s.sol`

- Imports `forge-std/Script.sol`.
- `run()` does:
  - `vm.startBroadcast()`
  - Deploy `DemoQuoteToken` once with `(name="xUSD Quote", symbol="xUSD", owner=msg.sender)`.
  - Deploy `DemoFanToken` 4 times with `(name, symbol)`:
    - `("Brazil Fan Token", "BRA")`
    - `("Argentina Fan Token", "ARG")`
    - `("France Fan Token", "FRA")`
    - `("Germany Fan Token", "GER")`
  - `vm.stopBroadcast()`
  - Write JSON to `deployments/<chain>/tokens.json` with shape:
    ```json
    {
      "chainId": <chain id>,
      "quote": { "symbol": "xUSD", "address": "0x..." },
      "teams": [
        { "symbol": "BRA", "name": "Brazil Fan Token", "address": "0x..." },
        { "symbol": "ARG", "name": "Argentina Fan Token", "address": "0x..." },
        { "symbol": "FRA", "name": "France Fan Token", "address": "0x..." },
        { "symbol": "GER", "name": "Germany Fan Token", "address": "0x..." }
      ]
    }
    ```
- Use `vm.serializeJson`/`vm.writeJson` or build the JSON manually with `string.concat`. **Do not** use `console.log` for the output — use `vm.toString` and `vm.writeFile`.
- Use `block.chainid` to namespace the directory: e.g. `deployments/31337/tokens.json` for anvil, `deployments/1952/tokens.json` for X Layer testnet.

### 2. `contracts/script/DeployCore.s.sol`

- Reads `tokens.json` from `deployments/<chainId>/` (use `vm.readFile` + `vm.parseJson`).
- Reads from env:
  - `POOL_MANAGER_ADDRESS` — the v4 PoolManager address. On X Layer testnet, **the actual canonical PoolManager address may not exist yet**; for the anvil pre-flight, the script MAY accept `POOL_MANAGER_ADDRESS=0x...` of a pre-deployed local PoolManager OR deploy one inline if the env is absent (see note below).
- `run()`:
  - `vm.startBroadcast()`.
  - Deploy `XCupLeagueRegistry(msg.sender)`.
  - Deploy `TeamPassport(msg.sender)`.
  - Resolve `IPoolManager poolManager` from env address.
  - **Mine the CREATE2 salt** so the resulting hook address has the required flag bits set in its low-order bytes. Required bits:
    ```
    AFTER_ADD_LIQUIDITY_FLAG = 1 << 11
    BEFORE_SWAP_FLAG         = 1 << 7
    AFTER_SWAP_FLAG          = 1 << 6
    requiredFlags = AFTER_ADD_LIQUIDITY_FLAG | BEFORE_SWAP_FLAG | AFTER_SWAP_FLAG
    ```
    (Read the exact constant values from `@uniswap/v4-core/libraries/Hooks.sol` — if `Hooks.BEFORE_SWAP_FLAG` and friends exist as named constants, use those; otherwise read `Hooks.ALL_HOOK_MASK` and the individual masks from the source.)
  - Try `import {HookMiner} from "@uniswap/v4-periphery/utils/HookMiner.sol"` first. If `HookMiner` is not present in the installed v4-periphery, write a local salt-search loop:
    ```solidity
    function _findHookSalt(
        address deployer,
        uint160 requiredFlags,
        bytes memory creationCodeWithArgs
    ) internal pure returns (bytes32 salt, address hookAddress) {
        for (uint256 i = 0; i < 200_000; i++) {
            bytes32 candidate = bytes32(i);
            address predicted = address(uint160(uint256(keccak256(abi.encodePacked(
                bytes1(0xFF), deployer, candidate, keccak256(creationCodeWithArgs)
            )))));
            if ((uint160(predicted) & uint160(0xFFFF)) == requiredFlags) {
                return (candidate, predicted);
            }
        }
        revert("HookSaltNotFound");
    }
    ```
    Pick whatever bit-mask actually matches the installed v4 — if the v4 build uses a 14-bit address-flag schema rather than 16, mask accordingly. Document the mask in the report.
  - Deploy the hook via `new XCupLiquidityLeagueHook{salt: salt}(poolManager, registry, passport, msg.sender)`.
  - Assert `address(hook).code.length > 0` and `(uint160(address(hook)) & uint160(0xFFFF)) == requiredFlags` (or equivalent mask).
  - Register the four teams via `registry.registerTeam(...)`:
    - `teamId = keccak256(bytes(symbol))` — write a helper `bytes32(uint256(keccak256("BRA")))`-style.
    - Pass token address from the tokens.json read.
    - `metadataURI = ""` for MVP.
  - `vm.stopBroadcast()`.
  - Write JSON to `deployments/<chainId>/core.json`:
    ```json
    {
      "chainId": <chain id>,
      "poolManager": "0x...",
      "registry": "0x...",
      "passport": "0x...",
      "hook": "0x...",
      "hookSalt": "0x...",
      "teams": [
        { "symbol": "BRA", "teamId": "0x...", "token": "0x..." },
        ...
      ]
    }
    ```

### 3. `contracts/script/utils/HookFlagsHelper.sol`

A tiny pure library wrapping the three flag constants the installed v4 actually exports:

```solidity
library HookFlagsHelper {
    function requiredFlags() internal pure returns (uint160) {
        return uint160(
            Hooks.BEFORE_SWAP_FLAG |
            Hooks.AFTER_SWAP_FLAG |
            Hooks.AFTER_ADD_LIQUIDITY_FLAG
        );
    }
}
```

If the installed v4 names these differently (e.g. `BEFORE_SWAP`/`AFTER_SWAP`/`AFTER_ADD_LIQUIDITY` without `_FLAG` suffix), follow the installed convention and document.
