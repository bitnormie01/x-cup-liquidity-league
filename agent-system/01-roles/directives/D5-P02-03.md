# Directive — D5 for P02-03

## Goal

Add Foundry tests for `DemoFanToken`, `DemoQuoteToken`, and `TeamPassport`. Cover every happy path and every revert path on these three leaf contracts, with line coverage ≥ 95% on each file. This is the first test phase in the project — establish the `contracts/test/` directory and a clean naming convention that later phases (P03-02 Registry tests, P04-04 Hook tests) will follow.

## Scope (In)

- Create the `contracts/test/` directory by adding the three test files below. No README, no helpers, no shared base contract — these contracts are simple enough that direct `Test` inheritance is the right call.

- `contracts/test/DemoFanToken.t.sol`:
  - SPDX `MIT`, `pragma solidity 0.8.26;`.
  - Imports:
    - `import {Test} from "forge-std/Test.sol";`
    - `import {DemoFanToken} from "../src/DemoFanToken.sol";`
  - Contract name: `DemoFanTokenTest is Test`.
  - Storage:
    - `DemoFanToken internal token;`
    - `address internal owner = address(0xA11CE);`
    - `address internal alice = address(0xB0B);`
    - `address internal bob = address(0xCAFE);`
  - `function setUp() public` deploys with `token = new DemoFanToken("Brazil Fan Token", "BRA", owner);`.
  - Required test functions (each exactly one assertion theme — keep them tight):
    - `test_ConstructorSetsMetadataAndOwner`: assert `token.name() == "Brazil Fan Token"`, `token.symbol() == "BRA"`, `token.decimals() == 18`, `token.owner() == owner`.
    - `test_OwnerCanMint`: `vm.prank(owner); token.mint(alice, 5 ether);` then assert `token.balanceOf(alice) == 5 ether`.
    - `test_NonOwnerCannotMint`: `vm.prank(alice); vm.expectRevert(abi.encodeWithSelector(Ownable.OwnableUnauthorizedAccount.selector, alice)); token.mint(alice, 1 ether);`. You will need `import {Ownable} from "@openzeppelin/contracts/access/Ownable.sol";` for the selector.
    - `test_FaucetMintFirstCallMintsFaucetAmount`: call `token.faucetMint(alice);` (no prank required — anyone can call) and assert `token.balanceOf(alice) == token.FAUCET_AMOUNT()` and `token.lastFaucetAt(alice) == block.timestamp`.
    - `test_FaucetMintRevertsDuringCooldown`: call `token.faucetMint(alice);` once, then expect the next call inside the cooldown to revert with `abi.encodeWithSelector(DemoFanToken.FaucetCooldown.selector, block.timestamp + token.FAUCET_COOLDOWN())`. Use `vm.expectRevert(...)` immediately before the second `token.faucetMint(alice);`.
    - `test_FaucetMintSucceedsAfterCooldown`: call once, then `vm.warp(block.timestamp + token.FAUCET_COOLDOWN() + 1);` and call again; assert `token.balanceOf(alice) == 2 * token.FAUCET_AMOUNT()`.
  - No fuzz tests. No `vm.skip(true)`. No `console.log`.

- `contracts/test/DemoQuoteToken.t.sol`:
  - Same structure as `DemoFanTokenTest`, but for `DemoQuoteToken`. Contract `DemoQuoteTokenTest is Test`.
  - In `setUp`: `token = new DemoQuoteToken(owner);` (the quote token constructor takes only the owner; `name`/`symbol` are hard-coded to `"X Cup Demo USD"` / `"xUSD"`).
  - `test_ConstructorSetsMetadataAndOwner`: assert `token.name() == "X Cup Demo USD"`, `token.symbol() == "xUSD"`, `token.decimals() == 18`, `token.owner() == owner`.
  - Mirror the other five tests from `DemoFanTokenTest` with `DemoQuoteToken` in the revert selector and storage type. The behavior is identical; the symbol assertion is the only differentiator.

- `contracts/test/TeamPassport.t.sol`:
  - SPDX `MIT`, `pragma solidity 0.8.26;`.
  - Imports:
    - `import {Test} from "forge-std/Test.sol";`
    - `import {TeamPassport} from "../src/TeamPassport.sol";`
  - Contract: `TeamPassportTest is Test`.
  - Storage:
    - `TeamPassport internal passport;`
    - `address internal owner = address(0xA11CE);`
    - `address internal alice = address(0xB0B);`
    - `address internal bob = address(0xCAFE);`
    - `bytes32 internal constant BRA = bytes32("BRA");`
    - `bytes32 internal constant ARG = bytes32("ARG");`
  - `function setUp() public` deploys with `passport = new TeamPassport(owner);`.
  - Required test functions:
    - `test_MintHappyPathSetsAllState`: `vm.prank(alice); uint256 id = passport.mintPassport(BRA);` then assert:
      - `id == 0`
      - `passport.ownerOf(0) == alice`
      - `passport.tokenIdOf(alice) == 0`
      - `passport.teamFanCount(BRA) == 1`
      - `passport.hasPassport(alice) == true`
      - `passport.teamOf(alice) == BRA`
      - `passport.isSupporter(alice, BRA) == true`
      - `passport.isSupporter(alice, ARG) == false`
      - `passport.nextTokenId() == 1`
      - Read the struct via `passport.passportOf(alice)` and assert `exists == true`, `teamId == BRA`, `mintedAt == uint64(block.timestamp)`.
    - `test_MintEmitsPassportMintedEvent`: use `vm.expectEmit(true, true, true, true); emit TeamPassport.PassportMinted(alice, 0, BRA);` before `vm.prank(alice); passport.mintPassport(BRA);`. (Declare the event locally on the test contract OR reference it via `TeamPassport.PassportMinted` — Foundry supports the latter via the qualified-event syntax. If the qualified syntax causes a build error on the installed forge-std, fall back to declaring the event on the test contract with the exact same signature.)
    - `test_MintRevertsOnZeroTeamId`: `vm.prank(alice); vm.expectRevert(TeamPassport.InvalidTeam.selector); passport.mintPassport(bytes32(0));`.
    - `test_DoubleMintByOneFanReverts`: mint once for alice, then `vm.prank(alice); vm.expectRevert(TeamPassport.AlreadyMinted.selector); passport.mintPassport(ARG);`.
    - `test_TransferFromReverts`: mint passport id 0 to alice, then `vm.prank(alice); vm.expectRevert(TeamPassport.Soulbound.selector); passport.transferFrom(alice, bob, 0);`.
    - `test_SafeTransferFromNoDataReverts`: mint to alice, then `vm.prank(alice); vm.expectRevert(TeamPassport.Soulbound.selector); passport.safeTransferFrom(alice, bob, 0);` (the 3-arg overload).
    - `test_SafeTransferFromWithDataReverts`: same as above but the 4-arg overload: `passport.safeTransferFrom(alice, bob, 0, "");`.
    - `test_DifferentFansMintDistinctTokenIds`: mint BRA for alice then ARG for bob. Assert alice's id is 0, bob's id is 1, `passport.teamFanCount(BRA) == 1`, `passport.teamFanCount(ARG) == 1`, `passport.nextTokenId() == 2`.
    - `test_UnknownFanReturnsDefaults`: without any minting, assert `passport.teamOf(alice) == bytes32(0)`, `passport.hasPassport(alice) == false`, `passport.isSupporter(alice, BRA) == false`.

- Run all of the following from inside `contracts/`, paste verbatim output into the report's Tests table:
  - `forge build`
  - `forge fmt --check`
  - `forge test -vvv`
  - `forge test --match-contract "(DemoFanToken|DemoQuoteToken|TeamPassport)Test" -vvv`
  - `forge coverage --report summary` and paste the rows for `src/DemoFanToken.sol`, `src/DemoQuoteToken.sol`, and `src/TeamPassport.sol`. If a row is below 95% line coverage, add the missing tests before reporting DONE. If `forge coverage` errors with the "stack too deep" or via-ir requirement, switch to `forge coverage --report summary --ir-minimum` and note the flag in the report.
