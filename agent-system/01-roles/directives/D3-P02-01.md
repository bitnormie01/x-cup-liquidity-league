# Directive — D3 for P02-01

## Goal

Implement two OpenZeppelin v5 ERC-20 contracts under `contracts/src/`: a parameterized `DemoFanToken` (the same source will later be deployed 4× as BRA / ARG / FRA / GER) and a hard-coded `DemoQuoteToken` (xUSD). Both expose owner-only `mint` and a cooldown-gated public `faucetMint`. No deployments, no tests yet (those land in P02-03), no pools, no hook wiring.

## Scope (In)

- Create `contracts/src/DemoFanToken.sol`:
  - SPDX `MIT`, `pragma solidity 0.8.26;`.
  - Imports: `import {ERC20} from "@openzeppelin/contracts/token/ERC20/ERC20.sol";` and `import {Ownable} from "@openzeppelin/contracts/access/Ownable.sol";`.
  - `contract DemoFanToken is ERC20, Ownable`.
  - Constructor signature: `constructor(string memory name_, string memory symbol_, address owner_) ERC20(name_, symbol_) Ownable(owner_)`. Do not pre-mint any supply.
  - Constants (declare exactly these names and values):
    - `uint256 public constant FAUCET_AMOUNT = 1_000 ether;`
    - `uint256 public constant FAUCET_COOLDOWN = 4 hours;`
  - Storage: `mapping(address => uint256) public lastFaucetAt;`.
  - Custom error: `error FaucetCooldown(uint256 nextAvailableAt);`.
  - Functions:
    - `function mint(address to, uint256 amount) external onlyOwner { _mint(to, amount); }`.
    - `function faucetMint(address to) external` that:
      - reads `uint256 last = lastFaucetAt[to];`.
      - if `last != 0 && block.timestamp < last + FAUCET_COOLDOWN`, reverts with `FaucetCooldown(last + FAUCET_COOLDOWN)`.
      - sets `lastFaucetAt[to] = block.timestamp;` BEFORE the mint (checks-effects-interactions ordering).
      - `_mint(to, FAUCET_AMOUNT);`.
  - NatSpec: `@notice` on every external function (constructor, `mint`, `faucetMint`). Keep it to one line each — no `@dev` paragraphs.
  - Do not override `decimals()` — rely on the OZ default (18).
- Create `contracts/src/DemoQuoteToken.sol`:
  - SPDX `MIT`, `pragma solidity 0.8.26;`.
  - Same imports as `DemoFanToken`.
  - `contract DemoQuoteToken is ERC20, Ownable`.
  - Constructor signature: `constructor(address owner_) ERC20("X Cup Demo USD", "xUSD") Ownable(owner_)`.
  - Identical `FAUCET_AMOUNT`, `FAUCET_COOLDOWN`, `lastFaucetAt`, `FaucetCooldown`, `mint`, `faucetMint` surface as `DemoFanToken` (copy the shape — do not abstract into a shared base contract; the small duplication is intentional for MVP audit clarity).
- Run `cd contracts && forge build` and `forge fmt --check`. Both must pass cleanly. Paste verbatim output into the report Tests table.
- Remove `contracts/src/Placeholder.sol` if and only if it still exists and was the bootstrap stub from P01-01 (confirm via `git log -- contracts/src/Placeholder.sol`). If you remove it, also delete any `contracts/test/Placeholder.t.sol` companion test. The empty `forge test` baseline shifts to "0 tests, 0 passed" — note that in the report.
